# 19 - 禅タイマー

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: zen-garden-timer

## 概要
砂紋アニメーションとともに瞑想セッションをガイドする静謐なタイマー。Web Audio APIによるベル音・インターバルベル・ボックス呼吸ガイドを備え、設定はlocalStorageで記憶される。

## 機能
- Canvas砂紋アニメーション（波紋・粒子パターン）
- セッション時間：5分/10分/20分/カスタム
- SVGプログレスリング付き大型カウントダウン表示
- 開始/一時停止/リセット制御
- Web Audio APIによるベル音（開始・終了・インターバル）
- インターバルベル設定（なし/1分/2分/5分ごと）
- ボックス呼吸ガイド（4-4-4-4）ビジュアル
- 設定をlocalStorageで保存
